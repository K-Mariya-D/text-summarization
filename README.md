# Проект по суммаризации текста 

## Код написан в рамках курсовой работы МехМата ЮФУ. Текст работы можно посмотреть [по ссылке](https://hub.sfedu.ru/repository/material/801350464/)

Целью работы было сравнить экстрактивный и абстрактивный подходы к суммаризации текста. 
Для экстрактивного использовался метод Латентно-семантический анализ (LSA) на базе библиотеки Sumy. 
Для абстрактивного использовалась модель T5-small из библиотеки transformers от Hugging Face. 
Модель обучалась на датасете CNN/DailyMail. 

Здесь находится чистая версия проекта, все эксперементы и тестовые запуски можно посмотреть [в блокноте Google Colab](https://colab.research.google.com/drive/141XuKHcLbVa3gXzVvjVWSV0-8RVOFGy4?usp=sharing)
